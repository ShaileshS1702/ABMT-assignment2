# Mikrozensus preprocessing outputs

Generated by `../microcensus_preprocessing.ipynb` from the original survey tables.

Current persons are Neuchâtel residents observed Monday–Friday with a confirmed entirely within-boundary day. Check every trip origin and destination against `Boundary/neuchatel.shp`, transforming CH1903 / LV03 coordinates (EPSG:21781) to the boundary CRS. Boundary points count as inside. Foreign-country endpoints establish outside travel. Exclude the whole person if any endpoint is outside; unknown endpoint geography or unresolved travel status is excluded and audited separately. Keep all trips of each retained person, including intermediate home returns. Confirmed stay-home residents remain in the person table.

This is an endpoint-based definition, not a route-path test. The sample is conditional on an entirely local day and no longer represents all resident person-days.

- `microcensus_ne_weekday_persons.csv`: selected persons, unchanged original weights and attributes.
- `microcensus_ne_weekday_trips.csv`: all trips for the selected persons, with endpoint scope flags.
- `microcensus_day_scope_audit.csv`: every resident weekday respondent before the day filter, selection status and WP.
- `microcensus_resident_filter_audit.csv`: counts before applying the day filter.
- `OLD_microcensus_ne_weekday_persons.csv` and `OLD_microcensus_ne_weekday_trips.csv`: original resident-weekday outputs including cross-boundary travel, preserved before this change.

Formal comparisons still apply age >= 6 and WP weighting. Do not remove stay-home people by joining only to trips. Part 3 result tables and figures must be rerun before interpreting them as results for this new sample.
